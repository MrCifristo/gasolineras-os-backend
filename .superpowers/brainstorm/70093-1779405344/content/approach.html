A — Puppeteer (HTML → PDF)

Escribe HTML+CSS normal, Puppeteer lo renderiza con Chromium. Calidad idéntica a una web. Gráficas SVG reales. Cualquier diseño CSS funciona.

✓ Máxima calidad visual  ✓ Gráficas reales  ✓ Control total de diseño

⚠ Descarga Chromium (~170 MB)  ⚠ ~2–4s por PDF

B — PDFKit (dibujo programático)

Dibuja el PDF elemento por elemento con código: texto en coordenadas, líneas, rectángulos. Sin dependencias de sistema.

✓ Ligero (~5 MB)  ✓ Rápido (<500ms)  ✓ Sin Chromium

✗ Gráficas limitadas  ✗ Diseño complejo = mucho código  ✗ Tablas manuales

C — pdfmake (declarativo)

Defines el PDF como un objeto JSON con tablas, columnas y estilos. Buen soporte de tablas. Sin soporte nativo de gráficas.

✓ Tablas excelentes  ✓ Sin Chromium  ✓ Rápido

✗ Sin gráficas reales  ✗ Layouts limitados  ✗ Diseño rígido

Haz clic en tu opción preferida, o dime en el terminal si quieres más detalles de alguna.
